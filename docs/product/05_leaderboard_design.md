# 05 Leaderboard 策略排行榜设计

## 定位

Leaderboard 必须保留。

它不是“竞技场噱头”，而是新系统中非常重要的多策略、多 AI 交易员、多观点的量化结果对比中心。

从：

```txt
交易员竞技场 / 收益榜
```

改造成：

```txt
多 AI 交易员 / 多策略 / 多观点的量化评估与对比中心
```

## 适用对象

- AI 投研员 / AI 交易员
- ETF 轮动策略
- 基金筛选策略
- 期货择时策略
- 多资产配置策略
- 人工策略基准
- 指数基准

## 策略风格

- 红利防御型
- 成长进攻型
- 宏观配置型
- 商品周期型
- 低波稳健型
- 趋势择时型
- 均值回归型
- 风险平价型

## 排名指标

### 收益类

- 累计收益
- 年化收益
- 超额收益

### 风险类

- 最大回撤
- 波动率
- VaR
- 回撤恢复时间

### 性价比

- Sharpe
- Calmar
- Sortino

### 稳定性

- 月度胜率
- 连续亏损期
- 收益分布

### 策略行为

- 换手率
- 调仓频率
- 持仓集中度

### 决策质量

- 预测命中率
- 观点一致性
- 证据充分度

### Agent 表现

- 工具调用成功率
- 报告质量
- 风险提示命中率

### 组合贡献

- 对组合收益贡献
- 对风险贡献
- 相关性贡献

## 页面结构

```txt
顶部：说明 + 关键指标摘要

筛选器：
  - 资产类型
  - 策略风格
  - 时间区间
  - 运行模式
  - 风险等级

主体：
  - LeaderboardTable
  - StrategyRankCard
  - AgentRankCard

图表：
  - 收益对比
  - 回撤对比
  - 风险收益散点图

详情：
  - AgentPerformanceDetail
  - StrategyComparisonDetail
```

## 文案原则

不要使用：擂台、厮杀、爆仓、币圈、加密交易竞技场。

推荐使用：策略对比、量化评估、风格比较、收益风险表现、多 Agent 投研表现、组合贡献。
